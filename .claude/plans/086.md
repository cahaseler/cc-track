## Plan: Document git.defaultBranch Configuration

### Current Situation
The `git.defaultBranch` configuration option exists in the code but is completely undocumented:
- Not mentioned in README.md
- Not included in the template track.config.json
- No user-facing documentation exists

The feature works as follows:
1. First checks `git.defaultBranch` in track.config.json (highest priority)
2. Falls back to GitHub API detection
3. Then git remote HEAD detection
4. Then git config init.defaultBranch
5. Finally defaults to "main"
