## Found the Bug: Setup Process Doesn't Create Required Directories

### Root Cause Identified
The cc-track initialization/setup process has a gap:
- **`cc-track init`**: Only creates `.claude/` and `.claude/commands/` directories
- **`cc-track setup-templates`**: Only copies template files to `.claude/` (no directory creation)
- **`/setup-cc-track` command**: Runs the above commands but doesn't create `tasks/` or `plans/` directories

The `capture-plan` hook DOES create these directories if missing (lines in capture-plan.ts):
```typescript
if (!fileOps.existsSync(plansDir)) {
  fileOps.mkdirSync(plansDir, { recursive: true });
}
if (!fileOps.existsSync(tasksDir)) {
  fileOps.mkdirSync(tasksDir, { recursive: true });
}
```

But in the walt project, the hook appears to be failing silently before reaching this code.

### The Problem
The walt project went through setup but is missing `.claude/tasks/` and `.claude/plans/` directories. When you exit planning mode:
1. The branch gets created successfully (you're on `381-add-typescript-aware-linting-rules`)
2. But the capture-plan hook fails before it can create the directories
3. No task file is created, no active task is set

### Solution Plan

1. **Fix the setup-templates command**
   - Add directory creation for `tasks/` and `plans/` to `src/commands/setup-templates.ts`
   - These directories should be created alongside other template files

2. **Alternative: Add to init command**
   - Could add `tasks/` and `plans/` directory creation to `src/commands/init.ts`
   - This ensures they exist before any hooks run

3. **For the walt project specifically**
   - Manually create the missing directories as a quick fix
   - Or re-run setup after we fix the command

4. **Add validation**
   - The setup process should verify all required directories exist
   - Log warnings if directory creation fails in hooks

This is a clear bug in cc-track's initialization process - it assumes these directories will be created by the hook, but the hook might fail before reaching that code.
