TASK_099 - SDK migration revealed tight coupling between SDK and CLI versions. The --setting-sources flag introduced in SDK 0.1.14 isn't supported by older CLI versions (1.0.124), causing runtime failures. This wasn't documented in migration guide.

PostToolUse hook for Edit/Write/MultiEdit was intentionally disabled at session start due to Claude Code crashes. This is important context - the hook wasn't accidentally removed, Craig explicitly requested it be disabled. Code review tools lack this session context and will incorrectly flag it as a problem.
