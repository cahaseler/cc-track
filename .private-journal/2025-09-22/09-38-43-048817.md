## Project Notes

The cc-track hook system now properly outputs single JSON responses. Key insight: the command pattern used here separates execution (runHookCommand) from output handling (applyCommandResult). All commands should follow this pattern - return CommandResult objects and let the framework handle output. The tests added specifically verify no direct stdout writes occur, which is a good pattern for testing command-line tools. Also learned that when Claude Code shows "Unexpected non-whitespace character after JSON", it often means duplicate output rather than malformed JSON.
