# Reference Documentation

The reference documentation that was previously stored here (hooks, commands, statusline, SDK docs) were copies of Anthropic's Claude Code documentation.

**Up-to-date documentation is now available via the official Anthropic SDK Development plugin.**

To access current Claude Code documentation:
1. Install the Anthropic SDK Development plugin in Claude Code
2. Use the `/docs` command or ask Claude about Claude Code features directly

The plugin provides accurate, current documentation for:
- Hooks (PreToolUse, PostToolUse, etc.)
- Slash commands
- Status line configuration
- Claude Code SDK / Agent SDK
- And more

This approach ensures you always have access to the latest documentation rather than potentially outdated copies.
