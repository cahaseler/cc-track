function stripMarkdownWrapper(content: string): string {
  const trimmed = content.trim();
  if (trimmed.startsWith('```')) {
    return trimmed
      .replace(/^```[a-z]*\n?/i, '') // Remove opening with optional language
      .replace(/\n?```$/i, '')        // Remove closing
      .trim();
  }
  return trimmed;
}
```

**Analysis:**
- ✅ Properly handles language specifiers (e.g., `markdown`, `typescript`)
- ✅ Case-insensitive matching with `/i` flag
- ✅ Optional newline handling with `\n?`
- ✅ Safe fallback returns original content if no wrappers detected
